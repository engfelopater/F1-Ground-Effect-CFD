# Numerical Modeling of Ground Effect and Downforce in Formula 1 Vehicles

A simplified CFD-based numerical study of Formula 1 aerodynamics using:

- Finite Volume Method (FVM)
- SIMPLE pressure–velocity coupling
- k-ω SST turbulence modeling
- Grid convergence & GCI analysis
- Python/MATLAB post-processing

## Topics Covered
- Ground effect aerodynamics
- Ride-height optimization
- Diffuser-angle analysis
- Numerical error analysis
- CFD convergence validation

- LaTeX

- MATLAB-style visualization
